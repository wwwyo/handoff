# 相関する証拠を独立した票として数えない。

- Status: Accepted
- Date: unknown

`NAME_FROM_CONTENT` の role では accessible name が textContent 由来で、`textQuote` と同じ文字列を見ている。独立に数えると、**ラベル変更後に古いラベルを持つ別要素が相関した2票を得て、`selector` しか一致しない正しい候補（1票）を 2-1 で上回り `confident` な誤指定になる**。`A11ySignature` に `nameFrom` を持たせ、`content` のときは1票に畳む。**`aria-label` 由来は textContent と独立なので畳まない** — 一律に畳むと `confident` が不必要に減る
