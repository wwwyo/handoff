# push をやめて pull にした（2026-07-30）

- Status: Accepted
- Date: 2026-07-30

Claude Code の実行中セッションへ外部から入力を差し込む正攻法は MCP polling や Stop hook ではなく **`channels`**（research preview、`notifications/claude/channel` でコンテキストへ直接注入）。ただし前提が「誰でもコメントできる・認証なし」だったので、**push は prompt injection の経路そのもの**になる。**認証なしと push は両立しない**という整理に落ちた。認証を捨てるなら push も捨てる
